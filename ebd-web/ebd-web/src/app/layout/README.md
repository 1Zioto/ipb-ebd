# Governança e Diretrizes do Template Sakai (PrimeNG)

> **⚠️ REGRA CRÍTICA - NÃO MODIFICAR ESTE TEMPLATE SEM AUTORIZAÇÃO PRÉVIA**
> 
> O template visual oficial desta aplicação é o **Sakai** para **PrimeNG (Angular)**.
> 
> 1. **Proibição de Modificação Estrutural ou Substituição**: É estritamente proibido alterar o layout base, substituir ou remover o template Sakai.
> 2. **Solicitação de Autorização Obrigatória**: Caso qualquer demanda, prompt ou solicitação envolva modificar a fundação do template Sakai ou migrar para outro template, **solicite autorização expressa do usuário responsável antes de prosseguir**.
> 3. **Extensão sem Quebra**: Novos módulos, páginas e formulários devem consumir os componentes PrimeNG e as classes utilitárias de superfície (`surface-card`, `text-muted-color`, `border-surface`, `Aura preset`), sem alterar os componentes do núcleo de layout (`app.layout`, `app.topbar`, `app.sidebar`, `app.menu`, `layout.service`).
